## 三、整改过程中新发现并已处理的问题

1. 选项后的分支对白是连播，原测试等不到下个选择就误判卡住——测试已改为“点完对白再等选择”。
2. 第二章配餐关原来只有预算没有餐谱数据，`cards` 缺失会白屏——已补成 12 元 4 格、8 张食物卡、必须含主食/蔬菜/蛋白。
3. “看依据”与“看道具”两个按钮叠在同一位置导致下层按钮点不到——改为同一行排列。
4. 调查簿按 flag 过滤时，没走过的分支会导致空簿——改为章末固定展示三条记录。
5. 随机事件在静态可达性检查里被当成孤岛——QA 已把事件池视为出边。

## 五、结论

P0 的四件事（记录与结局判定、第二章三分支与章末便签、知识便签接入、表情与场景）与 P1 的主要系统（物件探索、调查簿、随机事件池）已经落地并通过自动化验证。
剧本主干现在能跑通“核实来源 → 三条记录 → 三分支 → 三段标签 → 采购与随机事件 → 指南试行 → 三结局”的完整链路。
剩余缺口集中在收尾层（结局相册、片尾卡、解锁页）与美术层（讨论室背景、第四表情、快门声），不影响主线达成条件。
