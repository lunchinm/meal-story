## 一、剧情与状态（核心，最重的改动）

### 1. 选项去向 / 条件 / flag 全部编译进引擎（修复 P0）
- **问题**：`tools/convert-to-webgal.py` 原来忽略 `choice.next` / `showIf` / `flag`，所有选项都线性往下走：第四章选「先发布通用版」也会进入试行；选「先不改」也会记「完成修订」；第二章回访分支会串线。
- **修复**：
  - `choice.next` → 真实 `jumpLabel:t_<目标id>`；
  - `showIf`（含 `flag` / `notFlag` / 多旗标组合，含 `done:all` 聚合）→ WebGAL 原生 `(条件)->` 选项语法，不满足的选项直接不显示；
  - `option.flag` → `setVar:flag_<san(flag)>=1`，随引擎存档/回想/回退一起保存与恢复；
  - `record.flag` 同样写入引擎变量。
- **验证**：`tests/acceptance-endings.mjs` 实测「先发布通用版」→ `e_normal`；「试行 + 按反馈修订」→ `e_hidden`（见验收记录）。

### 2. 分支（branch）改为引擎条件跳转（修复 P0）
- **问题**：原来 `branch` 只 `setVar:branch=<id>` + 无条件跳 `fallback`，靠主题层 170ms 轮询碰运气；`a3-hidden-gate` 的隐藏支线（`a3-photo1-3`）从未可达。
- **修复**：规则编译为 `jumpLabel:t_<next> -when=<flags条件>;`（多旗标支持 all/any），不再依赖前端轮询；`fallback` 兜底仍保留。
- **验证**：`tests/acceptance-branch.mjs` 实测无 flag 走 fallback（偶遇记录），有 flag 走 PHOTO 隐藏支线。

### 3. 随机事件改为运行期随机（修复 P0）
- **问题**：原为构建期 Python `random`（每次构建固定一个）；且 R1/R2 事件播完会串进后续事件、三个记录全部入账。
- **修复**：`setVar:rnd_<id>=random(0,2);` + 三条 `jumpLabel -when=rnd==N`，每次游玩真正随机；事件结束后按剧本 `next` 汇合。

### 4. 三结局正式可达并展示（修复 P0）
- `ending` 节点不再被 `intro` 黑屏吞掉，改为 `setVar:ending=<id>` + 结局标题句；主题层按 `ending` 变量渲染正式结局面板（正文 / 行动建议 / 解锁清单）。
- 流程图（flowchart.json 与自绘 FLOW_ITEMS）结局名同步为真实结局标题。

## 二、引擎与「上一句」（P1-1）

- **根因**：旧 `__wgRewind` 只挪 `currentSentenceId`，不恢复舞台/场景栈/变量/回想，同场景也会留下错误舞台状态，跨章必坏。
- **修复**：改为复用原生 `jumpFromBacklog(length-2)`（WebGAL 官方回想跳转），并：
  - `jumpFromBacklog` 改为 `async`：先 `await sceneFetcher` 完整加载场景再恢复状态，消除跨场景竞态；
  - 跳转前统一 `stopAuto() + stopFast() + stopAllPerform()`，快进/自动中回跳不再失控。
- **附带**：打开菜单/回想/流程图前统一停 auto/fast（`__wgStopAllPlay`），菜单里不再残留播放。

## 三、菜单与界面串台（P1-2 / P2-2）

- `nativePanelOpen()` 探测补上 `[class*="Options"]`，选项页不再漏判导致菜单里点不到返回/标题。
- 删除了 `#paper-esc { display:none !important }` 的旧规则（它把「返回/标题」纸条永久隐藏了）。
- 标题菜单点击「开始/继续/读档」现在正确置 `gameStarted`，从选项节点直接开局（无台词的调试跳关）也能正常进入游戏而不卡标题。
- 去掉 Escape 兜底（Escape 实际打开 PanicOverlay，会盖住一切）。
- 启动期只保留一张纸质启动幕：`index.html` 预载样式先把 `#root` 隐藏，等纸质标题就绪再显形，消除“封面 / PRESS / 蓝页”三连闪。
- `nativePanelOpen()` 排除原生标题页（`Title` 祖先）；修复高分辨率下把原生标题误判成面板、纸质标题被收起、“返回/标题”浮条常驻的问题。
- 原生标题层整体隐藏（仍可由程序点击），避免白字菜单压在木桌背景上。

## 四、调查簿 / 记录（P3-2）

- 调查簿面板升级为正式可回翻页面：纸质排版、空态提示、「合上调查簿」按钮。
