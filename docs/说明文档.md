## 1. 这是什么

四川大学华西临床医学院「合理膳食 · 免疫基石」创意宣传大赛的互动叙事作品：
一个 WebGAL 引擎上的 Galgame 风 Web 游戏，玩家跟着四个学生调查校园套餐宣传里的问题，
中间穿插群聊、看图核实、配餐、瓶身对比、调查簿等互动。

- 线上：https://lunchinm.github.io/meal-story/
- 仓库：`lunchinm/meal-story`（GitHub Pages，由 Actions 自动构建发布）
- 技术形态：**WebGAL 4.6.7（静态 SPA）+ 一层自绘"纸质调查簿"UI（theme-inject.js）+ 构建期脚本转换**

## 2. 三分钟跑起来（本地）

```powershell
# 1) 准备引擎（仅第一次）：把 WebGAL 源码放在 ../WebGAL-src，已打补丁并 build 过
cd ..\WebGAL-src ; yarn webgal:build

# 2) 把游戏内容同步进 dist，并起本地服务
cd ..\meal-story
python tools\sync-dist.py local          # 拷 assets / 场景 / config / 主题脚本
python tools\serve.py                    # 直接服务引擎 dist，默认 8080，可用 PORT=8123 指定
# 浏览器打开 http://127.0.0.1:8081/
```

> ⚠️ 每次改完 `webgal-game/` 下的东西，都要重跑 `sync-dist.py`（它会重建 dist/game 并注入主题）。
> ⚠️ 本地端口被别的程序占过（QQ 抢过 8082），起不来时先换端口。

## 4. 剧本数据模型（最重要的一节）

`content/act1..4.json` 是一份带**显式字段**的结构化剧本，共 816 个节点、12 种类型：

| 类型 | 数量 | 关键字段 |
|---|---|---|
| `say` | 740 | `speaker` `channel` `scene` `actor` `expr` `card` `seg` `prop` |
| `choice` | 33 | `question` `hint` `options[{text, reply}]` |
| `record` | 23 | `flag` `label`（写进调查簿） |
| `branch` | 6 | `rules[{flags, all, next}]` `fallback` |
| `random` | 1 | `pool[{id, next}]` |
| `chapter` | 4 | `title` `image` |
| `ending` | 3 | `title` `body[]` `action` `unlocks[]` |
| `plate` | 2 | `budget` `slots` `cards[]` `check` `tip` |
| `evidence` | 2 | `prompt` `posterText[]` `need` `hint` |
| `notebook` | 2 | `title` `entries[{label,text}]` |
| `compare` | 1 | `offers[{name,front,back}]` `worse` |
| `explore` | 1 | `title` `items[{label,summary}]` |

**`say.channel` 决定界面**：`chat` 161 句（群聊，不配音）、`stage` 399 句（文本框，有配音）、
空 180 句（等同 stage）。`say.card`（k1/k2/k3）标出 7 句知识点台词。

改剧本 = 改 JSON，然后跑 `python tools\convert-to-webgal.py`。**不要手改 `webgal-game/scene/*.txt`**。

## 5. 呈现层设计

### 5.1 两条界面线

- **群聊**：右侧纸面板，气泡 + 姓名；玩家的话先以底部"回复纸签"出现，点一下才发出去（变右侧绿气泡并自动推进一句）；图片消息是缩略图，点开大图、点空白关闭。
- **文本框**：左下角色名 + 米色纸卡；选项是纸签**精确覆盖**在引擎条目上（纸签 `pointer-events:none`，真实点击落到引擎控件，保证能点）。

### 5.2 界面判定：靠台词里的不可见标记

最稳的一招，也是踩过坑之后定的方案：

- 转换器给群聊台词前缀 `U+200B`，文本框台词前缀 `U+200C`
- 运行时读首字符判断，显示前剥掉

不依赖引擎变量（`setVar` 在等待点击时读不到）、也不比文本（`“”` / `""`、`……` / `...` 对不上就判错）。

### 5.3 互动节点

剧本里的 `plate / evidence / notebook / compare / explore / ending` 会展开成左上纸面面板，
字段原文照搬（题目、提示、预算、菜品、两瓶正反面文案、调查簿条目、结局正文与解锁）。

### 5.4 记录与分支

- `choice` → 选项的 `next` 生成真实 `jumpLabel`；`showIf`（含 `flag` / `notFlag`）编译成 WebGAL 原生选项条件；选项 `flag` 与 `record.flag` 都写入引擎变量 `flag_<flag>=1`，随存档/回想恢复
- `record` → 转换器写 `setVar:rec=<序号>` + `setVar:flag_...`，运行时从引擎变量重建调查簿并提示「已记入调查簿：xx」
- `branch` → 规则直接编译为 `jumpLabel:t_<目标> -when=<flags条件>`（支持 all / any），不再依赖前端轮询；`fallback` 兜底
- `random` → 运行时 `setVar:rnd=random(0,N)` + `when` 分支，每次游玩不同
- `ending` → `setVar:ending=<id>`，主题层按变量渲染结局面板（正文/行动/解锁）

### 5.5 引擎出口（自绘层能用的东西）

补丁脚本 `.github/patch-engine.py` 往 `backToTitle.ts` 追加了：

| 出口 | 用途 |
|---|---|
| `__wgBackToTitle()` | 回标题 |
| `__wgNext()` | 主动推进一句 |
| `__wgJump(label, scene?)` | 跳 label（可跨场景） |
| `__wgClosePanels()` | 关原生面板（menu/backlog/flowchart） |
| `__wgTextBox(bool)` / `__wgQuickBar(bool)` | 收/放原生文本框与快捷栏 |
| `__wgOpenMenu(tag)` / `__wgOpenBacklog()` / `__wgOpenFlowchart()` | 打开原生面板 |
| `__wgStopVocal()` / `__wgVocalSrc()` | 停当前配音 / 读当前句该有的配音 |
| `__wgGetVar(key)` | 读引擎变量 |
| `__wgRewind(n)` | 回退 n 句：复用原生 `jumpFromBacklog`（回想快照，恢复舞台/场景栈/变量），跨章可用 |
| `__wgStopAllPlay()` | 停 auto / 快进（打开菜单、回想、流程图、回退前统一调用） |
| `__wgDebugStart` | 开局直接进入指定场景 + 段落（跳关用） |

## 6. 构建与发布

### 6.1 CI 流程（`.github/workflows/webgal-pages.yml`）

1. checkout `OpenWebGAL/WebGAL@4.6.7`
2. 关掉 `startPreviewSyncRuntime()`
3. `python3 .github/patch-engine.py .webgal-src/packages/webgal/src`（引擎补丁，**幂等**）
4. `yarn install` → `yarn parser:build` → 组装 `game/`（assets + scene + config + jump.json）
5. `yarn webgal:build`
6. `cp webgal-game/theme-inject.js` → `python3 .github/inject_theme.py`（注入 `<script src="theme-inject.js?v=…">`）
7. 发布 GitHub Pages

### 6.2 两个必须记住的坑

1. **`inject_theme.py` 里的 `?v=` 必须每次改**（现在 `20261119w`）。不改的话浏览器/CDN 会一直用旧主题，你改了也"看不到生效"。
2. **提交前确认 `.git/index.lock` 没被占**（这机器上反复出现），否则 `git commit` 静默失败，而 CI 会发布旧提交。

### 6.3 本地改完要做的三步

```
python tools\convert-to-webgal.py     # 剧本 → 场景脚本（改过 content 才需要）
python tools\export-*.py              # 剧本 → 运行时表（改过 content 才需要）
python tools\sync-dist.py <版本号>     # 同步进 dist（改过 webgal-game 一定要）
```
