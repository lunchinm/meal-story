## 4. 怎么改内容（最常见的三件事）

### 4.1 改台词
1. 编辑 `content/actN.json` 对应节点
2. `python tools\convert-to-webgal.py`
3. `python tools\export-line-meta.py` / `export-chat-meta.py` / `export-ui-data.py` / `export-story-meta.py`
4. `python tools\sync-dist.py <新版本号>`；同时把 `tools/patch-dist.py` 与 `.github/inject_theme.py` 里的 `?v=` 改成同一个版本号
5. 提交 → 触发 CI（或自动）

### 4.2 换素材
- 背景 → `assets/bg/`（1920×1080 webp），立绘 → `assets/ch/`（900px 高）
- 配音 → `assets/voice/<节点id>.mp3`（文件名必须等于剧本节点 id，否则不会挂 `-vocal`）
- 图片消息 → `tools/make-chat-images2.py` 生成后跑 `sync-chat-images.py`

### 4.3 加一段互动
在剧本里加对应类型节点（`plate/evidence/notebook/compare/explore`），
`tools/export-ui-data.py` 会自动把它导出成运行时面板数据；面板渲染在 `theme-inject.js` 的 `renderTask()`。

## 6. 交接要点（最容易踩的）

1. **`.git/index.lock`**：这台机器上反复出现，`git commit` 会静默失败 → 每次提交后 `git log -1` 确认，再推。
2. **`?v=` 版本号**：不改就等于没发布（浏览器拿到旧主题）。
3. **本地端口**：8082/8090 被系统或 QQ 占过，`serve.py` 起不来就换 8123。
4. **不要手改** `webgal-game/scene/*.txt`：它是生成物，改剧本 JSON 重新生成。
5. **引擎补丁是 CI 打的**：本地预览需要先对 `WebGAL-src` 跑一次 `patch-engine.py` 再 `yarn webgal:build`，否则 `__wg*` 出口全都没有。
