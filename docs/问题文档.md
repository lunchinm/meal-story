# 《今天吃什么？——校园膳食调查簿》问题文档

> 已知问题、复现方式、优先级、涉及文件。按优先级从高到低。
> P0 = 阻断/必现；P1 = 明显缺陷；P2 = 体验问题；P3 = 素材/内容待补。

## P1-1 「上一句」按钮点了不回退

- **现象**：纸面右上角 `← 上一句` 可点，但画面不动。
- **原因**：引擎在"等待玩家点击"的状态下，`continueSentence()` 不执行；`__wgRewind` 已经把
  `currentSentenceId` 往回挪到上一条 `say`，但引擎不重新跑那一句。
- **涉及**：`theme-inject.js → buildNav()` / 引擎出口 `.github/patch-engine.py → __wgRewind`。
- **两条可选路线**：
 - **A（推荐，稳）**：改成打开原生「回想」并自动定位到上一条，让玩家点一下跳回 —— 引擎原生支持。
 - **B**：继续啃引擎内部（需要 `stopAllPerform()` + 重新走 perform 管线，风险高）。

## P1-2 聊天/文本框偶发串台（已大幅收敛，仍需盯）

- **现象**：过去聊天台词会掉进下方文本框，聊天面板消失、历史清空。
- **现状**：已改成"台词内嵌不可见标记（`U+200B` 群聊 / `U+200C` 文本框）"判定，线上验证连续多句都正确。
- **风险点**：任何绕过转换器手写场景脚本的地方，都不会带标记 → 会退回"文本框"。
- **涉及**：`tools/convert-to-webgal.py`（写标记）、`theme-inject.js → markerOf / stripMarker / lineInfo`。

## P1-3 回归测试无法发现语义错误

- **现象**：32 + 9 条用例全绿时，实际仍有"界面串台、发言人错配、同一句重复"等问题。
- **原因**：用例只断言"有没有气泡/有没有文字"，没有断言"这句该进哪个界面""发言人是否与剧本一致""同一句只出现一次"。
- **建议**：把剧本导出的逐句清单（`LINE_BY_ID` / `LINE_META`）作为断言基准，逐句对比
  「界面类型 / 发言人 / 文本」三要素；或直接以人肉试玩代替（历史试玩记录见 `docs/archive/试玩记录.md`）。

## P2-1 语音策略仍有边角

- 群聊不配音、文本框配音已按 `channel` 区分；`guardVocal` 以引擎 `playVocal` 为准，无配音句会立刻停。
- **残余风险**：极快连点时，极少数情况仍可能听到上一条尾巴（浏览器音频管线延迟）。
- **涉及**：`theme-inject.js → kickAudio / guardVocal`，引擎 `__wgVocalSrc / __wgStopVocal`。

## P2-2 原生快捷栏与自绘图标的归属

- 需求是"不要重绘底栏，把缺的功能加到原生栏上"。
- **现状**：原生栏完整保留；缺的两个功能（上一句 / 调查簿）以同风格小图标放在纸面右上角，
- **为什么不直接插进原生栏**：那排按钮在缩放容器里（`getBoundingClientRect` 返回负坐标），且 React 重渲染会移除插入的节点。
- **可选改进**：改 `config.txt` 里的 GUI 模板，用 WebGAL 官方方式加自定义按钮（工作量大，但最干净）。

## P2-3 设置页部分选项对自绘 UI 无效

- 文本大小/字体/文本框不透明度只作用于原生文本框；自绘纸卡样式固定。属预期内但不一致。

## P2-4 道具图位置与大小

- 道具图曾按立绘尺寸渲染（半屏遮挡），已缩到 0.3 并挪到右下；仍可能与立绘/面板叠，逐场景再调。

| 用途 | 现状 | 需要的图 |
|---|---|---|
| 宣传海报（核实节点） | 空白海报 + 文字列表 | 一张带 4 行文案的合成海报 |

## P3-2 record / branch / random 的语义完整度

- `record`：已入账（flag + 提示 + 调查簿面板），但"调查簿"尚未做成可回翻的正式页面（目前是浮层列表）。
- `branch`：规则里引用的部分 flag（如 `rec:选择试行及试行对象`）在 23 条 record 中找不到同名项，
  这些分支实际会走 `fallback`。需要核对剧本或补 record。
- `random`：构建期随机（每次构建结果不同），不是运行时随机；若要"每次游玩不同"，需要改成运行时。

## P3-3 剧本细化

- 部分 `say` 的 `seg` 为空（act2 全部缺 `seg`），导致跳关只能按"整章"跳，不能按段跳。
  补齐 `seg` 后 `jump.json` 会自动生成更细的入口。
