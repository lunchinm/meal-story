# 《今天吃什么？——校园膳食调查簿》测试用例（全量）

- 版本：v1.0（2026-11-17）
- 被测对象：`webgal-game/`（WebGAL 4.6.7 运行时 + 自绘纸卡主题），线上 https://lunchinm.github.io/meal-story/
- 代码基线：`b7c1b09`（云端可取的 GitHub 版本）
- 线上与仓库的差异：线上多一个 `game/flowchart.json`（内容是 WebGAL 示例「示例游戏主线/入口选择」，不是本作剧情），仓库里没有这个文件；其余脚本、主题、config 与仓库逐字一致
- 编写依据：本仓库的脚本、主题注入代码、配置与线上实跑，不引用未核实的说法
- 规模：9 个模块，80 条用例；其中 26 条可脚本化，54 条需人工或需本地环境

## 一、怎么用

```bash
# 云端/本地都能跑，只要给一个可访问的地址
node tools/qa-cloud.mjs http://127.0.0.1:8099/
node tools/qa-cloud.mjs https://lunchinm.github.io/meal-story/

# 产物：qa-out/report.md、report.json、shots/*.png
```

首次跑要装依赖与浏览器：`npm i`、`npx playwright install chromium`。
跑之前把地址换成本地发布目录（`npx serve` / `python3 -m http.server`，注意 `.txt` 必须带 `charset=utf-8`）。

判定口径：

| 标记 | 含义 |
| --- | --- |
| 通过 | 实测符合预期 |
| 不通过 | 实测违背预期，记为缺陷 |
| 待复测 | 云端无头环境受干扰，结论不可信，需本地真机复测 |
| 需人工 | 听感、观感、设计风格这类脚本判不了的 |
| 未跑 | 本轮没执行，只给步骤 |

优先级：P0 = 阻断交付（玩不下去/没声音/页面错乱），P1 = 明显影响体验，P2 = 打磨项。

## 十二、本轮实测（云端，2026-11-17 深夜）

环境：阿里云 2C4G，无头 Chromium 159，本地静态服务（仓库 HEAD 资源）+ 线上 Pages 各跑一遍；已装 Noto Serif CJK 并做 `SimSun/Songti SC` 别名（不装会全是豆腐块，那是环境问题，不是作品问题）。

| 结果 | 条数 | 用例 |
| --- | --- | --- |
| 通过 | 12 | A-01/02/05/07、B-01、E-01/02、G-01/02/03/04/05 |
| 不通过 | 10 | A-03/04/06/15、A-02b、B-06/07、C-02、D-01/02 |

两环境差异只有两处：线上 `flowchart.json` 返回 200（仓库副本 404），线上标题层偶发多一个 0×0 空节点导致菜单计数变成 12。

脚本编号与本文档有两处对不上：脚本里的 `C-01` 是 BGM 在播（对应本文档 C-07 的一半），`D-03` 是面板样式采样（对应本文档 D-06）。其余编号一致。

线上与本地服务结论一致，说明不是网络问题。

## 十三、缺陷单

### D1（P0）原生开始层压在自绘标题上，未点开始就出现原生提示

- 现象：标题页同时出现 `PRESS THE SCREEN TO START` 与 `LANGUAGE SELECT` 十语种按钮，叠在自绘标题与菜单上，菜单被压住。
- 证据：`shots/A-01-title.png`；DOM 为 `.html-body__title-enter`（z-index 14）下的 `.title-enter__container`（z-index 15）。
- 用例：A-03、A-04 不通过。
- 定位：`webgal-game/theme-inject.js` 只把原生菜单文字所在 div 设成 `opacity:0`，没有处理 `title-enter` 这一层。
- 修法：开始前就把 `.html-body__title-enter` 设为 `display:none`（或 `pointer-events:none` + 层级压到纸卡之下）。

### D2（P0）点了开始，旧层不消失，还抢走点击

- 现象：点「开始游戏」后原生层仍在（`PRESS THE SCREEN TO START` 继续显示），要再点一次屏幕才淡出；鼠标点对话区 3 次只有 1 次推进，键盘空格正常。
- 证据：`shots/A-06-after-start.png`、`shots/v2-talk.png`；A-06、B-02 实测。
- 用例：A-06、A-08 不通过/待复测。
- 修法：进游戏（出现 `TextBox_Container`）时把 `title-enter` 整层移除，而不是只隐藏菜单文字。

### D3（P0）配音全程不播

- 现象：526 个 mp3 已拷进 `game/vocal/`，但场景脚本里没有一句绑定语音；跑 15 句，`/vocal/` 请求 0 条。
- 依据：WebGAL 语音要在台词后加参数，如 `比企谷八幡:刚到而已 -V3.ogg;`；`webgal-game/scene/*.txt` 里 0 处 `-V`。
- 用例：C-01、C-02 不通过。
- 修法：转换器按句子 id 输出 `-V<句id>.mp3`，文件名与 `assets/voice/*.mp3` 对齐（现在是 `a1-100.mp3` 这种，需要映射表）；改完用 C-01 回归。

### D4（P1）流程图：配置开了，入口没有，数据是引擎示例

- 现象：`config.txt` 写了 `Enable_flowchart:true`；线上 `game/flowchart.json` 能取到（HTTP 200），但内容是 WebGAL 自带的示例——`name` 为「示例游戏主线」，节点叫「入口选择」；仓库 `b7c1b09` 里根本没有这个文件。界面上菜单和底部栏都没有「流程图」。
- 依据：WebGAL 要求两步——配置开 + `game/flowchart.json`；数据里没有本作的 `sceneName`，入口自然不会出现。
- 用例：D-01、D-02 不通过；D-03（节点覆盖）无从谈起。
- 修法：用脚本结构生成主图（start + 四章 + 三分支 + 三结局，`sceneName` 指向 `act1.txt`…`act4.txt`），再按设计稿补纸质配色，最后用 D-06 验收。

### D5（P2）两个 Live2D 脚本 404

- 现象：`lib/live2d.min.js`、`lib/live2dcubismcore.min.js` 均 404，控制台跟着报错。
- 用例：B-06、B-07 不通过；H-03 同因。
- 修法：项目不用 Live2D，从 index 移除这两个 script 引用，或补文件。

### D6（P2）自绘快捷条少了三个入口

- 现象：自绘只有回想/自动/快进/存档/选项 5 个图标，原生条被 CSS 移到屏幕外（`left:-9999px`），「标题/全屏/隐藏」鼠标点不到。
- 用例：A-15 不通过、G-06 未跑。
- 修法：补「标题」「全屏」两个图标，或在选项面板里给出入口。

### D7（待复测）推进响应慢

- 现象：云端无头环境空格推进中位 6.2s、15 次只有 3 次推进。
- 判断：与 D2 抢事件叠加，且无头浏览器计时不可信，先不当缺陷；本地真机用 B-02~B-05 复测，若仍 >1s 再立案。
- 另有一条同类观察：标题层偶发被建两次（第二个是 0×0 空节点），画面不受影响，但说明 `buildTitle` 没做幂等，建议顺手加个 `if (document.getElementById('paper-title')) return;`。

## 十四、环境差异（别把这些当成作品缺陷）
