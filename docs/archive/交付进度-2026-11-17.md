## 一、阅读体验（对比传统 GAL 的最大缺口）

| 功能 | 说明 | 位置 |
| --- | --- | --- |
| 自动播放 | 右上「自动」或按 **A**，按字数节奏往下走；遇到选项、关卡、面板自动停 | `src/ui/stage.ts` `setAuto/scheduleAdvance` |
| 快进已读 | 右上「快进」或按 **S**，只跳已读过的句子，遇到没读过的自动关掉 | `state.readNodes` + `setSkip` |

| 三通道音量 | 设置面板里 BGM / 音效 / 角色语音 三条独立滑杆，立即生效并存盘 | `src/settings.ts` + `src/audio.ts` |
| 自动播放停顿时长 | 0.6—3.0 秒可调，同样存盘 | 同上 |
| 右键隐藏界面 | 想看立绘和背景时一键收起 UI，再按右键恢复 | `toggleUiHidden` |
| 快捷键 | A 自动 / S 快进 / L 回想 / Esc 关闭面板 | `src/main.ts` |

实际体验：内容没砍一句，靠自动播放把 740 句的点击量降到几十次。

## 四、测试过程中发现并修掉的问题

1. 主对白的推进逻辑挂在带 `MouseEvent` 参数的处理器上，自动播放调不动 → 抽成无参 `proceed()`。
2. 选项/关卡在场时仍能开自动播放 → `setAuto` 增加阻挡。
3. 道具面板打开时自动播放还在推进 → 面板打开清计时器、计时器回调再判断一次遮罩层、收起后恢复。
4. `showProp` 收起后不恢复自动播放 → 补 `scheduleAdvance()`。
5. 调查簿断言命中了隐藏条目（strict mode）→ 测试限定第一条。
