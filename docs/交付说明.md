## 场合与表现

| 场合 | 表现 | 配音 |
| --- | --- | --- |
| 群聊 / 手机消息 | 手机聊天窗口，消息气泡，玩家发言右对齐 | 不配 |
| 当面（食堂、窗口、课桌、便利店） | 立绘 + 对白框 | 逐句配 |
| 玩家心声（你） | 对白框，只出字幕 | 不配 |

- 聊天记录按段重置：回到当面场景再进群聊，是新的一屏
- 群聊里的选项是底部快捷回复，点了先发出玩家气泡

## 道具

挂在对应台词上的面板，点击展开：

- 群里的宣传图（底图 + 文案）
- 瓶子正面 / 背面（配料、净含量）
- 营养成分表（每 100 毫升一列，标注整瓶 500 毫升）
- 课表便签（含被划掉的那行）
- 食堂菜牌（菜名、类别、价格）
- 套餐实物照

标签类用 HTML 渲染，字号保证清晰，不用图片。

## 可旋转瓶身

对比关两瓶饮料可以按住左右拖动转动：标签绕瓶身一周，前半圈是正面设计，后半圈是配料表与营养表；松手有惯性，键盘左右键也能转，另有「转到背面」一键转位。

## 预览跳关

标题页右下角「预览」：列出四章、五个关卡、三个结局，点击直接跳过去，不用重头玩。进游戏后按钮自动收起。
