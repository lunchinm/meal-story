### 运行时机制（动之前必须知道）

- 界面判定：转换器给群聊台词前缀 `U+200B`、文本框 `U+200C`；主题读首字符并剥掉。不要改回比对文本或读引擎变量。
- 状态：选项 flag 与 `record.flag` 写入 `setVar:flag_<san(flag)>=1`，主题从 `GameVar` 重建调查簿；读档/回想不丢。
- 分支：`branch.rules` 编译为 `jumpLabel:t_<next> -when=<flag条件>`；`random` 用 `setVar:rnd=random(0,N)` 运行期抽。
- 结局：`ending` 节点写 `setVar:ending=<id>`，主题按 `UI_DATA` 渲染整页结算卡。
- 回退：`__wgRewind` 复用原生 `jumpFromBacklog`，跨章恢复舞台/变量；跳转前停 auto/fast。
- 启动流程（intentional，非闪现）：封面「合理膳食·免疫基石」→点击→纸质标题（银杏背景，非木桌）→开始游戏→「PRESS THE SCREEN」→点击→正文。见 `buildSplash/buildPress/showPress`。
- 面板判定：`nativePanelOpen()` 直接读引擎 `__wgGui()`（menu/backlog/flowchart），不再用 DOM 启发式；打开原生面板时收起自绘层，关闭后恢复。存档/读档/设置/回想用 `__wgOpenMenuTag(0/1/2)`/`__wgOpenBacklog` 打开，保证槽位与内容可见。
- 设置生效：`applyUserSettings` 把字号/字体/文本框不透明度应用到自绘纸卡。
- 配音：推进点击立即 `__wgStopVocal`，`kickAudio` 只播放与当前句匹配的音频，避免“我”句听到上一角色声音。
- 启动：`index.html` 注入 `#paper-preload` 先隐藏 `#root`，纸质标题就绪后显形；标题背景由主题自绘。
- Service Worker：WebGAL 自带离线 SW 会造成“更新后仍是旧页面”，已在 `inject_theme.py` / `sync-dist.py` 中改为始终注销，不要恢复注册。
- 原生面板：`nativePanelOpen()` 已排除原生标题和关闭态回想层；自绘层不再因面板打开而整体收起。

## 5. 发布

正常网络：

```powershell
git push origin main
gh workflow run "构建并发布 WebGAL 版" --ref main
```

本机到 github.com:443 常被阻断，但 `api.github.com` 与 `gh` 可用；可改用 GitHub Git Data API 上传 blob/tree/commit 并 PATCH `refs/heads/main`，再触发 workflow。注意：API 直推会让本地 git 历史与远程分叉（当前内容树一致、提交 SHA 不同）；网络恢复后先 `git fetch origin`，再 `git reset --hard origin/main` 对齐，不要直接 `git push`。发布前必须把三处版本号改一致：

- `.github/inject_theme.py`
- `tools/patch-dist.py`
- `tools/sync-dist.py <版本号>` 的参数

否则浏览器/CDN 仍拿旧主题。

## 6. 已知坑

1. **沉浸式翻译等扩展会改页面布局**：曾出现纸卡被推到屏幕外、只剩原生文本框。该站请关闭自动翻译，或用 InPrivate 验证。
2. GitHub Pages 的 `index.html` 有 10 分钟缓存；更新后可用 `?v=<版本号>` 强制取新入口。
3. 本机 `.git/index.lock` 偶发被占，提交后看 `git log -1` 确认。
4. 端口 8081 被占时用 `PORT=8123 python tools\serve.py`。
5. 任何“纸签/纸片”按钮保持 `pointer-events:none`，点击必须落到真实引擎控件或自绘可点层。
