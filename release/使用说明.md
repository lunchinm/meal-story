## 二、离线包（答辩现场、没网环境）

`release/meal-story-offline-20261122.zip`（约 46 MB）

1. **解压整个文件夹**，不要只把 `index.html` 拖出来；
2. 电脑需要装 **Python 3**（https://www.python.org/downloads/ ，安装时勾选 Add to PATH）；
3. 双击文件夹里的 **「启动游戏.bat」**，浏览器会自动打开（默认 http://127.0.0.1:8081/ ，端口被占用会自动换下一个）；
4. 关闭黑色命令行窗口即停止游戏服务；
5. 不要直接双击 `index.html`——浏览器会拦本地文件，游戏加载不出来（这一版会显示一张提示页，不会再白屏乱闪）。

适合拷到 U 盘带去没网的教室或答辩现场。

## 三、同一 WiFi 现场展示（不依赖外网）

在项目目录运行：

```powershell
python tools\share.py
```

终端会打印两个地址：

- `http://127.0.0.1:8081/` 本机自己看
- `http://192.168.x.x:8081/` 同一 WiFi 下的手机、其他电脑

第一次运行时 Windows 防火墙弹窗要选“允许访问”。关闭终端即停止。

## 五、常见问题

| 现象 | 处理 |
| --- | --- |
| 打开还是旧画面 | 访问时加后缀 `?v=20261122`，或在浏览器里清一次该站点数据 |
| 页面排版被撑坏、文字乱跳 | 关掉“沉浸式翻译”等自动翻译扩展（或换无痕窗口） |
| 白屏 | 走「启动游戏.bat」，不要双击 index.html |
| 没有声音 | 先点一下页面（浏览器禁止自动播放音频） |
| 存档没了 | 存档存在浏览器本地，清缓存或换浏览器会丢 |

## 六、我们这边怎么更新线上

**Surge（主链接）**

```powershell
node tools\deploy-surge.mjs
```

默认把 `.artifacts/surge-dist` 发布到 `.env` 里的 `SURGE_DOMAIN`，凭据读 `.env` 的 `SURGE_LOGIN` / `SURGE_TOKEN`（`.env` 已被 gitignore，不进仓库）。

**GitHub Pages（备用）**

Pages 现在由 **`gh-pages` 分支**提供（仓库设置里 Pages 的 Source 已改成 `gh-pages` / `/`）。更新步骤：把新成品目录的内容提交到 `gh-pages` 分支并推送即可，不用重新构建引擎。

注意事项：

- **`gh-pages` 分支里不要放 `CNAME` 文件**，否则 GitHub Pages 会把站点域名改成那个域名，`lunchinm.github.io/meal-story/` 就废了；
- `.github/workflows/webgal-pages.yml`（从源码构建的旧流程）现在闲置，别手动触发，触发会用旧源码覆盖线上；
- Surge 侧发布时 CNAME 由 surge 自己写，和 Pages 分支无关。

## 七、分享时的注意事项

1. 只发线上链接，不要把整个仓库或 `content/*.json` 发给观众；
2. 现场演示前先自己完整点一遍开头和一次结局，确认音量、全屏和网络；
3. 用离线包演示的话，提前在那台电脑上跑一遍「启动游戏.bat」，确认 Python 装好。
