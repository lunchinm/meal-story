# 怎么把《今天吃什么？》分享出去

## 方式一：直接发链接（推荐）

**https://lunchinm.github.io/meal-story/**

- 手机、电脑浏览器都能打开，不用装任何东西；
- 微信里点开如果被拦，选“在浏览器中打开”；
- 建议横屏，点右下角全屏按钮体验最好。

配套二维码：`分享/游戏二维码.png`，可以直接放进海报、PPT 或群公告。

## 方式二：同一 WiFi 现场展示（不依赖外网）

在项目目录运行：

```powershell
python tools\share.py
```

终端会打印两个地址：

- `http://127.0.0.1:8081/` 本机
- `http://192.168.x.x:8081/` 同一 WiFi 下的手机/其他电脑

第一次运行时 Windows 防火墙弹窗要选“允许访问”。手机和电脑连同一个 WiFi，直接开第二个地址即可。关闭终端即停止。

## 方式三：离线包

`分享/meal-story-offline-20261119af.zip`（约 45 MB）

- 解压整个文件夹，双击「启动游戏.bat」；
- 需要电脑装有 Python 3；
- 不要直接双击 `index.html`，浏览器本地跨域会白屏；
- 适合拷 U 盘带去没网的教室/答辩现场。

如果对方没有 Python，可以把解压后的 `dist` 内容拖到 https://app.netlify.com/drop ，几秒后会得到一个可分享的临时网址。

## 分享时的注意事项

1. 发线上链接即可，不要把整个仓库或 `content/*.json` 发给观众。
2. 如果对方打开还是旧画面，让他访问 `https://lunchinm.github.io/meal-story/?v=20261119af`，或在浏览器设置里清一次该站点数据。
3. 页面里如果装了“沉浸式翻译”等自动翻译扩展，可能把纸质界面撑坏；关掉该站点的自动翻译，或用无痕窗口。
4. 现场演示前先自己完整点一遍开头和一次结局，确认音量、全屏和网络。
